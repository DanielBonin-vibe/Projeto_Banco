# 🏦 Sistema Bancário em Python

Projeto de um sistema bancário desenvolvido em **Python**, utilizando **SQLite3** para persistência dos dados.

O projeto foi desenvolvido com o objetivo de praticar conceitos de **Python, Programação Orientada a Objetos, SQL, SQLite, modularização e operações com banco de dados**.

---

## 📌 Sobre o projeto

O sistema permite realizar operações básicas de um banco, como:

- Cadastro de clientes
- Abertura de contas
- Consulta de clientes
- Listagem de clientes
- Consulta de contas
- Consulta de saldo
- Depósitos
- Saques
- Transferências
- Fechamento de contas

O sistema possui uma interface simples através do terminal e utiliza um banco de dados SQLite para armazenar as informações.

---

## 🛠️ Tecnologias utilizadas

- **Python 3**
- **SQLite3**
- **SQL**
- Programação Orientada a Objetos (POO)
